# @aeroops/web

Next.js (App Router) + TypeScript ops console for staff: schedule, dispatch, bill,
train, maintain, report. Tailwind + shadcn/ui with per-tenant design tokens for
white-label.

This is a placeholder package. The `frontend-engineer` scaffolds the real Next.js
app during Phase 0 (auth + RBAC + multi-tenant shell), then builds screens
slice-by-slice from the architect's spec. See `THE-BIBLE.md` §2–§3.
