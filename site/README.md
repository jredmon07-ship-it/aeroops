# AeroOps project site

A small static site for AeroOps: self-contained HTML with inline CSS and inline SVG, one Google
Font (Fraunces, with a system-serif fallback so pages still work offline), and no build step.

## Pages

- `index.html`: the product overview (scheduling, training, maintenance, reporting), the
  open-source section, and the live-demo logins.
- `faq.html`: plain product questions (data security, mobile, FAA determinations, setup).
- `how-it-works.html`: the setup steps, checked against the real app.
- `terms.html` and `privacy.html`: short pages for the software and the public demo.

Copy rules: no em dashes in rendered copy, operator-defined rules only, no FAA-determination
claims, no testimonials, logos, or prices.

## 2026-10-10: money features removed

AeroOps no longer has billing, payments, dues, or QuickBooks features, so the billing hub, the
billing screenshot, the money FAQ items, and the Payments sections of Terms and Privacy were
removed. The license statement appears once, in the `#open-source` section on `index.html`.

The product screenshots (`shot-*.png`) were captured before the Billing nav item was removed and
should be recaptured.

## Deploy

Deploy the site (`scripts/deploy-site.sh`) only after the `jredmon07-ship-it/aeroops` repo is
public. Every "View on GitHub", issues, and license link on the site points at that repo and
returns 404 while it is private.

The site is plain static files, so any static host works (GitHub Pages, Vercel, Netlify,
Cloudflare Pages, S3). `index.html` is the entry point; opening it directly from disk also works.

The hero uses `hero-cessna.mp4` (an autoplaying background loop) and `hero-poster.jpg` (shown
before the video loads, and wherever the video cannot play). If either file is missing, the hero
still renders as a dark navy panel.
